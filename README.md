# INFLOWS

React + Vite landing page for $INFLOWS on BNB Chain.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The static production output is in `dist/`. Configure a static host to build with `npm run build` and serve `dist`.

Official X: https://x.com/inflows_bnb

Logo and favicon: `public/logo.png`. Contract and trading links are pending announcement.
